Executive Summary

I architected and delivered a production-grade monitoring dashboard for a multi-account financial system, tracking trading activity and wallet balances across multiple external providers in real time.

Version 1 was implemented in Angular with a strict backend mediation model. Version 2 was rebuilt in React, where I expanded a base UI template into a fully production-ready application — implementing authentication, RBAC, secure API orchestration, and a structured ingestion pipeline.

The system processed thousands of trade records daily, enforced project-level isolation, and maintained strict secret handling using Cloud Functions and Secret Manager. I owned the platform end-to-end across frontend architecture, backend services, data modelling, and infrastructure decisions.
